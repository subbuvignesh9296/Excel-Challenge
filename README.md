# **🏥 Healthcare Data Analysis Project**

# **📌 Project Overview**
* This project mainly focuses on healthcare analysis data to idntify patterns, trends, insight that help to improve decision making in healthcare industry. 
* This analysis include patient records, treatment details, hospital performance and cost using data analytics and visualization techniques.

# **🎯 Objectives**
* Analyse healthcare dataset to discover meaningfull insights.
* Identify hospital performance and healthcare cost
* Understand patients details and treatment trends
* Visualize healthcare KPIs using dashboard
* Support data-driven healthcare decision.
  
# **🛠️ Tools & Technologies**
* MS Excel: Primary tool for data cleaning, synthesis, and dashboarding.
* Functions:
     * XLookup
     * VLookup
     * Pivot table
     * IF()  Function
     * DatedIF() Function
     * Concat() Function
 * Data Visualization: Interactive Excel Dashboards using Donut and Pie charts.

# **📊 Key Features & Analysis**
* ** Data Integration: ** Merged multiple data sources (Customer Names, Medical Examinations, and Hospitalization Details) into a unified dataset.
*  **BMI Calculation:** Engineered formulas to calculate Body Mass Index for patient health assessment.
* **Risk Categorization**: Implemented diabetic status flags and health metrics to categorize patient risk levels.
* **Interactive Dashboard:** Developed a visual interface to track:Patient demographic distributions.Health trends and medical habit correlations.Comparative analysis of patient vitals across different categories.
